# موقع Socialdia + لوحة التحكم

موقع Socialdia Agency بنفس الحكاية المصورة (الكاميرا، اللوجو، مجسمات 3D، الدارك/لايت، عربي/إنجليزي) ومعاه **لوحة تحكم** على `/admin` فيها حسابين أدمن بصلاحيات كاملة.

## اللوحة بتتحكم في إيه؟
- **الصفحات:** إنشاء أي صفحة من أقسام جاهزة (غلاف، نص، نص + صورة، معرض، فيديو، خدمات، أعمال، مميزات، أرقام، أسئلة شائعة، آراء، لوجوهات، CTA، نموذج تواصل، HTML) وترتيبها وتكرارها وحذفها.
- **الهيدر:** أي صفحة تفعّل فيها "إظهار في الهيدر" بتظهر تلقائيًا في القائمة بنفس ستايل الموقع. ومن "قائمة الهيدر" ترتّب الصفحات والروابط الإضافية وتخفي وتظهر.
- **الخدمات:** إضافة/تعديل/ترتيب/إخفاء، وكل خدمة ليها صفحة خاصة وتتربط بمشاهد القصة.
- **الأعمال السابقة:** غلاف ومعرض صور وفيديو ونتائج وتصنيفات وفلتر.
- **الصفحة الرئيسية:** نصوص الهيرو والأرقام والختام، وأقسام إضافية قبل الختام. **مشاهد القصة:** النصوص والترتيب والإظهار.
- **آراء العملاء، اللوجوهات، الرسائل (صندوق وارد + CSV)، مكتبة الميديا (رفع صور)، التحويلات (Redirects).**
- **إعدادات الموقع:** الهوية واللوجو، التواصل (واتساب/إيميل/عنوان)، السوشيال، الألوان، المقدمة (بدون/مرة في الجلسة/كل زيارة)، تشغيل/إيقاف الـ 3D والحركات وزر واتساب، SEO، شريط إعلان، أكواد مخصصة (Analytics وغيره).
- **المديرين:** إضافة مدير جديد، ونسخ احتياطي JSON (تصدير/استيراد).

> مجسمات الـ 3D (كاميرا، لابتوب، كشكول…) ثابتة في الكود. من اللوحة تتحكم في نصوص المشاهد وترتيبها وتشغيل الـ 3D من عدمه، لكن مش في شكل المجسم نفسه.

## التركيب (حوالي 15 دقيقة)

### 1) Supabase (قاعدة البيانات)
1. ادخل https://supabase.com وأنشئ Project جديد (مجاني يكفي).
2. من **Authentication → Users → Add user → Create new user** أنشئ حسابين (إيميل + باسورد) وفعّل **Auto Confirm User**.
3. افتح ملف `supabase/schema.sql` وفي **آخر الملف** غيّر `ADMIN_ONE@example.com` و `ADMIN_TWO@example.com` لإيميلات الحسابين اللي عملتهم.
4. من **SQL Editor → New query** الصق محتوى الملف كله واضغط **Run**. (آمن تعمله تاني، مش بيمسح بيانات.)
5. من **Project Settings → API** انسخ **Project URL** و **anon public key**.

### 2) Vercel
1. ارفع محتوى هذا المجلد على GitHub (احذف أي `index.html` قديم من المشروع) أو ارفعه بـ `vercel` CLI.
2. في Vercel: **Settings → Environment Variables** ضيف:
   - `SUPABASE_URL` = الـ Project URL
   - `SUPABASE_ANON_KEY` = الـ anon public key
3. اعمل Redeploy. افتح `/admin` وسجّل بأي من الحسابين.

الـ anon key مصمم يبقى عام، والحماية بتتم بقواعد Row Level Security في `schema.sql`: الزائر بيقرا المنشور بس، والكتابة للأدمن بس.

## ملاحظات مهمة
- التعديلات بتظهر في الموقع خلال حوالي **30 ثانية** (كاش).
- لو الموقع ظهر برسالة "الموقع لسه مش متوصل" يبقى المتغيّرين ناقصين في Vercel.
- **بيانات التواصل فاضية** لحد ما تكتبها من الإعدادات → بيانات التواصل. زر واتساب ما بيظهرش إلا لما تحط الرقم.
- ماتحطش بيانات وهمية: الأعمال وآراء العملاء فاضية لحد ما تضيف الحقيقي.
- الصور: ارفعها من **مكتبة الميديا** (يفضل webp/jpg مضغوطة).
- لتشغيل نسخة محلية: حط المتغيّرين في البيئة واكتب `npm run dev` (مفيش حاجة تتسطّب).
- الاختبارات: `npm test` (بتشغّل سيرفر Supabase وهمي ومتصفح؛ محتاجة حزمة `playwright`).

## الهيكل
- `api/` دوال Vercel: `render.js` (كل صفحات الموقع)، `contact.js`، `config.js`
- `lib/` القراءة من Supabase وقوالب الصفحات والأقسام
- `public/assets/` الستايل والـ JS والـ 3D واللوجو، و`public/admin/` اللوحة
- `supabase/schema.sql` الجداول والصلاحيات والبيانات الأولية
